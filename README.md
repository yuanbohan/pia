# pi-go

面向学习与验证的 [Pi](https://github.com/earendil-works/pi) 核心能力 Go 语义移植。

项目以课程驱动：每一课同时完成源码拆解、Go 实现、测试、讨论记录和一次由学习者批准的提交。当前阶段聚焦 AI 协议、Agent Loop、coding tools 和 Goal Runtime，不实现 TUI，也不优先承诺公共 SDK。
